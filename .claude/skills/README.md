# Project skills

Claude Code loads these automatically for anyone who opens this repo. They are the
skills used to build Shackleton Station:

| Skill | Used for |
|---|---|
| threejs-fundamentals | Scene, renderer, game loop |
| threejs-lighting | Sun, shadows, earthshine, helmet lamp |
| threejs-geometry | Terrain, buildings, instanced rocks and plants |
| threejs-materials | PBR materials and reflections |
| threejs-interaction | Pointer lock and first-person controls |
| threejs-postprocessing | Ambient occlusion, bloom, tone mapping |
| threejs-textures | CC0 textures |
| threejs-performance | Draw calls and frame-time checks |
